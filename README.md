# Rust PortScanner
Simple port scanner implemented in Rust. Usable via GUI and per console. Should work on Win10/11 and on Linux-based systems like CachyOS and Debian 12.

To use the console version just start the executable from the console with the argument `--term`. Downloads of compiled binaries are available [here](https://github.com/Vincent0987123/rust-port-scanner/releases).
